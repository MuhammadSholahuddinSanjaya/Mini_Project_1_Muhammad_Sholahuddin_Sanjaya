saya disini ingin menjelaskan tentang tema mini project saya yaitu tentang sistem pendataan jadwal sepak bola.

untuk perulangan yang dipilih adalah sesuai yang diperintahkan pada soal yaitu menggunakan perulangan while

perulangan while cocok dengan tema saya dikarenakan untuk penambahan jadwal bola

saya disini memakai jenis variabel list kosong yang berfungsi untuk menyimpan semua data jadwal

setiap jadwal yang diinput akan disimpan di dalam list yang berisikan tuple dalam tiga elemen yaitu

nama Pertandingan, Nama Liga, Waktu pertandingan

program saya bisa melakukan 5 opsi yaitu:

1.Menambah data jadwal Pertandingan Sepak Bola

2.Menampilkan data Jadwal Pertandingan Sepak Bola

3.Mengubah data jadwal Pertandingan Sepak Bola

4.Menghapus data jadwal pertandingan sepak bola 

5.Keluar Dari Program
